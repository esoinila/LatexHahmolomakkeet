# LaTeX Character Sheets and Game Aids for a Modern TTRPG

This repository contains LaTeX files for character sheets, item cards, monster cards, and location descriptions for a tabletop role-playing game. The game is set in the modern day and revolves around themes of archaeology, ancient mysteries, conspiracy, and cosmic horror.

## Game Premise

The game appears to be centered around the exploration of ancient sites, the discovery of "Atlantian" technology, and the machinations of several secret factions. Players take on the roles of characters with backgrounds in archaeology, social media, and other relevant fields. The game mechanics include a "sanity" system, suggesting that players will confront sanity-threatening horrors. The "Fail Forward" character sheet system suggests a narrative focus where failure is not an endpoint but a driver of the story.

## Repository Contents

This repository is organized into several types of files:

*   **Character Sheets (`character_*.tex`):** These files contain the LaTeX source for pre-generated player characters. Each character has a unique background, abilities, personality traits, and equipment.
*   **Item Cards (`item_cards.tex`):** This file contains LaTeX source for creating item cards. The items are a mix of mundane adventuring gear, modern technology, and powerful "Atlantian" artifacts.
*   **Monster Cards (`monster_cards.tex`):** This file contains LaTeX source for creating monster cards. The monsters include mundane opponents, agents of secret factions, and supernatural entities.
*   **Site Descriptions (`site_*.tex`):** These files contain brief descriptions of locations that the players can explore. Each description includes an overview of the site, details about its "portal," puzzles, potential rewards, and consequences for failure.
*   **Name Signs (`namesign_*.tex`):** These files appear to be for creating name signs for each character, likely for use at the game table.
*   **Images (`*.jpg`, `*.png`):** The repository contains a large number of images used for character portraits, item illustrations, and location maps.
*   **PowerShell Scripts (`*.ps1`):** The `rebuild_tex.ps1` and `build_messages.ps1` scripts are likely used to automate the process of compiling the LaTeX files into PDFs.

## How to Use

To use these files, you will need a working LaTeX distribution (such as TeX Live, MiKTeX, or MacTeX). You can then compile the `.tex` files into PDFs using a LaTeX editor or the command line. The included PowerShell scripts may simplify this process for Windows users.

## Factions

The game world is populated by several factions, each with its own agenda:

*   **The Eagle Faction:** A mysterious organization that seems to be in control of ancient sites and artifacts. They are portrayed as manipulative and secretive.
*   **The Separatists:** A group that opposes the Eagle Faction and seeks to keep the past buried. They are depicted as using modern weapons and tactics.
*   **Delta Green:** A clandestine organization dedicated to containing paranormal threats and covering up their existence.

## The "Fail Forward" System

The character sheets are described as being for a "Fail Forward" system. This suggests that the game is designed to handle failure in a way that advances the narrative, rather than simply ending a scene or encounter.
